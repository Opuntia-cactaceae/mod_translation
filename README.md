# Переводчик модов: интеллектуальный инструмент автоматизированной локализации файлов игровых модификаций
## Описание проекта
Проект представляет собой инструмент, предназначенный для автоматической обработки файлов локализаций компьютерных игр.  
Основная цель — перевод текстов модификаций с сохранением синтаксической структуры и форматирования, чтобы готовые файлы корректно работали в игре.  

Инструмент решает следующие проблемы:
- машинный перевод "в лоб" нарушает структуру файлов локализации, что часто приводит к крашам и некорректному отображению текста;  
- служебные символы, переменные и специальные конструкции искажаются или удаляются;  
- пользователи вынуждены тратить время на ручную правку файлов после перевода.  

Подход:
1. Извлечение переводимого текста и отделение его от служебных конструкций.  
2. Перевод текста с помощью внешних API или локальных ML/DL-моделей.  
3. Постобработка и восстановление структуры файлов локализации.
